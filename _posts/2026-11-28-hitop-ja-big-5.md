# HiTOPに独自にBig Fiveの対応を追加したもの

| スペクトラム | サブファクター | Big Five的な対応(無理やり) | 症候群・特性の例 | 関連する障害 |
|---|---|---|---|---|
| 身体表現(暫定) | ― | 神経症傾向(身体への注意・不安) | 転換、身体化、頭痛、消化器症状 | 病気不安症、身体症状症 |
| **内在化** | 全体 | **神経症傾向 高** | 不安性、情動不安定、脆弱性、無能感 | ― |
| | 性的問題 | 神経症傾向 高(不安・自己意識) | ― | 興奮の困難、性欲低下、性交痛 |
| | 摂食病理 | 神経症傾向 高、誠実性 高(完璧主義・自己統制) | ― | 神経性やせ症、過食症 |
| | 恐怖 | 神経症傾向 高、外向性 低(社交不安)、誠実性 高(強迫の儀式) | 対人不安、パニック、洗浄、確認 | 社交不安症、強迫症、パニック症 |
| | 苦痛 | 神経症傾向 高、外向性 低(快感消失) | 不快気分、快感消失、不眠、易怒性 | うつ病、全般不安症、PTSD |
| | 躁病 | 外向性 高、開放性 高、誠実性 低 | 高揚、過活動な認知、無謀な自信過剰 | 双極I型・II型 |
| **思考障害** | ― | 開放性 高(風変りな側面)、(神経症傾向 高) | 精神病性、解体、風変り、特異な信念 | 統合失調症スペクトラム、統合失調型PD |
| **脱愛着** | ― | **外向性 低**、(開放性 低) | 引きこもり、親密性の回避、快感消失 | 回避性PD、シゾイドPD |
| **脱抑制外在化** | ― | **誠実性 低** | 衝動性、無責任、注意散漫、危険行動 | ― |
| | 有害物質使用 | 誠実性 低、神経症傾向 高、開放性 高(経験希求) | アルコール・薬物使用 | 物質関連障害 |
| | 反社会的行動 | 誠実性 低、協調性 低 | 攻撃、詐欺、衝動性、反抗性 | 反社会性PD、素行症、ADHD |
| **敵対的外在化** | ― | **協調性 低** | 冷淡さ、欺瞞性、誇大性、操作性、支配性 | 自己愛性PD、演技性PD、境界性PD |

**読み方のポイント**
- 太字は、対応が比較的よく支持されている主軸です(内在化=神経症傾向、脱愛着=低外向性、脱抑制=低誠実性、敵対=低協調性)。
- 括弧書きや副次的な対応は、報告が一貫しない、または私の推測を含む部分です。
- 思考障害と開放性の対応は、Big Fiveの「開放性」の病理的な極(風変りさ)に限られ、通常の開放性(好奇心・創造性)とは別物とされます。
- ADHDは主に誠実性の低さ(不注意・計画性の低さ)と結びつきますが、神経症傾向とも関連します。
